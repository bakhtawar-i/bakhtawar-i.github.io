# bakhtawar-i.github.io

Personal academic homepage. Live at https://bakhtawar-i.github.io

Plain HTML/CSS, no build step. Edit `index.html` directly and push to `main`;
GitHub Pages redeploys automatically within a minute or two.

## Files
- `index.html` — all page content
- `style.css` — all styling
- `assets/` — photo.jpg, cv.pdf

## Adding content
- **Publication** — copy an `.entry` block in the Publications section
- **Project** — copy an `.entry` block in Selected Projects
- **News item** — copy a `<tr>` row in the News table, keep reverse-chronological order
