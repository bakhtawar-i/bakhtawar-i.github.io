# Setting this up as your GitHub Pages site

1. Create a new GitHub repo named exactly: **yourusername.github.io**
   (replace "yourusername" with your actual GitHub username — this exact
   naming is what makes GitHub serve it as your personal site)
2. Push these files (index.html, style.css, assets/) to the root of that repo.
3. In the repo's Settings > Pages, confirm the source is set to the main branch, root.
4. Your site will be live at https://yourusername.github.io within a few minutes.

## Before you publish, edit these placeholders in index.html:
- your.email@example.com  -> your real email (appears twice)
- github.com/yourusername  -> your GitHub profile and repo links (appears in each project entry)
- linkedin.com/in/yourusername -> your real LinkedIn URL
- assets/photo.jpg and assets/cv.pdf -> add the real files

## To add a new project or news item later:
Copy one .entry block (in the Selected Projects section) or one <tr> row
(in the News table) and edit the text. No build step — just edit the HTML directly.
